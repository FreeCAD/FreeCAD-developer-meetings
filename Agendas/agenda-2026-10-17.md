2. **FreeCAD 26.3 release** (chennes)
   - 26.3 was branched, more info and schedule: https://github.com/FreeCAD/FreeCAD/discussions/32821
   - All PRs target main. Please add the 26.3 milestone to your PRs which need to be in 26.3 or tag me so I can assign it. Focus is on fixes.
   - Please assign the `backport releases/FreeCAD-26-3` label to the same PRs and tag me for automatic backports of merged PRs.
   - Add blocking issues if something critical is broken and tag @maxwxyz.
   - Translators get strings now from the release branch. Limit UI changes and no UI/string changes after the first RC (approx. 2 weeks after branching).
   - Update [release notes](https://wiki.freecad.org/Release_notes_26.3) and document your own changes!
   - For reviewing, use the Release Priority view: https://github.com/orgs/FreeCAD/projects/40/views/11 (Manually ranked: Blockers, PRs that fix blockers, PRs that fix regressions, PRs that are approved, other bugfixes.

3. **Meetings Repo and Crow** (chennes)
   - We have a lot of groups having a lot of meetings
   - Taking minutes is not fun
   - So @sliptonic has created "Crow", the meeting-bot. It takes minutes and auto-creates a PR for them
   - The new repo is https://github.com/FreeCAD/Meetings/
   - This meeting's minutes and agenda will move there starting next month

4. **Digital Ocean Migration** (chennes)
   - Digital Ocean has discontinued their Open Source Credits program
   - They were overpriced anyway, even with the credits 💸
   - So the FPA is moving our infrastructure to OVH
   - All data stays hosted in Frankfurt (no change)
   - This will take time and involve service outages during backup periods
  
5. **Lens Server Compromise** (chennes)
   - The FPA sponsors a live test installation of Lens at lens.freecad.org
   - It was compromised this week
   - The route is known and mitigation is in process
   - The server is offline in the interim
   - Treat anything stored there as exposed, especially user email addresses and all FCStd files
   - Details will be published as Security Advisories as soon as mitigations are implemented and a new release made
